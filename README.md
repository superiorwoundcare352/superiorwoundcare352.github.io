# Superior Wound Care, LLC — website

Single-page static site (HTML/CSS, no build step) for Superior Wound Care, LLC, hosted on GitHub Pages.

- `index.html` – page content, SEO meta, Open Graph, and MedicalBusiness JSON-LD
- `styles.css` – styles (brand colors sampled from the logo: navy #1A365B, sage #7B8B74, lavender #8F7BA4)
- `assets/` – logo (original + optimized web versions), emblem crop for favicon/nav, Open Graph image

The "Request a visit / referral" form uses `mailto:` (no backend), addressed to cora@superiorwound352.com with hope@superiorwound352.com on CC.
